# Alcances del sitio web corporativo de Grupo EGD

## Objetivo del proyecto

Diseñar y desarrollar el sitio web corporativo de Grupo EGD, cliente de Inside Out. El sitio reunirá bajo una misma identidad a las cuatro empresas que forman parte del grupo:

- Enlace GD
- EGD Aftersale & Detailing Center
- EB Cars
- CENTUR Blindajes

El sitio contará con un encabezado, una navegación y un estilo visual consistentes, con el propósito de que los usuarios perciban a las cuatro marcas como parte de un mismo grupo empresarial.

## Alcance general

El proyecto incluye:

- Diseño visual personalizado para Grupo EGD.
- Unificación visual de las cuatro empresas dentro del mismo sitio web.
- Aplicación de una navegación compartida y consistente.
- Adaptación de la identidad de cada empresa dentro del sistema visual general del grupo.
- Desarrollo responsivo para computadoras, tablets y celulares.
- Navegación accesible mediante mouse, teclado y dispositivos táctiles.
- Optimización básica dentro del sitio para buscadores, también conocida como SEO on-page.
- Configuración técnica del sitio web.
- Publicación del sitio web.

## Estructura del sitio

El sitio estará formado por nueve páginas principales:

1. **Inicio**
2. **Nosotros**
3. **Empresas**
4. **Servicios**
5. **Contacto**
6. **Enlace GD**
7. **EGD Aftersale & Detailing Center**
8. **EB Cars**
9. **CENTUR Blindajes**

### Organización de las páginas de empresas

Las páginas individuales de cada empresa estarán agrupadas dentro de la sección **Empresas**, utilizando la siguiente estructura:

- `Empresas/EnlaceGD`
- `Empresas/EGD Aftersale`
- `Empresas/EBCars`
- `Empresas/CENTUR Blindajes`

## Contenido

El contenido específico de cada página y sección se ajustará en conjunto con Inside Out y Grupo EGD durante la etapa de diseño.

## Resultado esperado

Un sitio web corporativo responsivo y publicado que presente a Grupo EGD como una organización unificada, permita conocer sus cuatro empresas y facilite el acceso a la información general, los servicios y los medios de contacto del grupo.
