# Grupo EGD

Sitio corporativo de Grupo EGD y sus empresas: Enlace GD, EGD Aftersale &
Detailing Center, EB Cars y CENTUR Blindajes.

## Stack

React Router 8, React 19, TypeScript, Vite y Tailwind CSS 4.

## Desarrollo

```powershell
npm install
npm run dev
```

## Verificación

```powershell
npm run typecheck
npm run build
```

## Documentación

- `AGENTS.md` — reglas para cualquier colaborador o agente.
- `CLAUDE.md` — guía de skills y operación para Claude Code.
- `docs/ARQUITECTURA.md` — rutas y límites de componentes.
- `docs/BRANDING.md` — decisiones de marca y materiales pendientes.
- `docs/HANDOFF.md` — punto de continuación.
- `docs/PLAN.md` — fases de implementación.
- `docs/GOTCHAS.md` — riesgos conocidos.
