# Bitácora de sesiones

Cada modificación debe añadir un archivo `YYYY-MM-DD_descripcion-corta.md` con:

1. Objetivo de la sesión.
2. Cambios realizados y decisiones tomadas.
3. Archivos relevantes.
4. Verificación ejecutada y resultado exacto.
5. Gotchas nuevos o actualizados.
6. Siguiente paso y cualquier revisión humana requerida.

No registres secretos, valores de variables de entorno ni información privada.
